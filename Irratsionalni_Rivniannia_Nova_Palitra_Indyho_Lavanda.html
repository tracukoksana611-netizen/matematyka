Теорія: головне за § 7

1. Що таке ірраціональне рівняння?

\(\displaystyle \sqrt{x+3}=x-1\)

Це рівняння, у якому змінна міститься під знаком кореня.

2. Теорема 7.1: непарний степінь

\(\displaystyle a=b\iff a^{2k+1}=b^{2k+1}\)

Піднесення обох частин рівняння до одного непарного натурального степеня дає рівносильне рівняння.

3. Теорема 7.2: парний степінь

\(\displaystyle a=b\Longrightarrow a^{2k}=b^{2k}\)

Піднесення до парного степеня може додати сторонні корені. Кожен кандидат перевіряємо в початковому рівнянні.

4. Область допустимих значень

\(\displaystyle \sqrt{f(x)}\ \Rightarrow\ f(x)\geq0\)

Для кореня парного степеня підкореневий вираз має бути невід’ємним.

5. Рівняння-наслідок

\(\displaystyle \text{корені початкового}\subseteq\text{корені наслідку}\)

Після піднесення до квадрата коренів може стати більше, але не менше.

6. Метод заміни змінної

\(\displaystyle t=\sqrt{x},\quad t\geq0\)

Повторюваний радикал замінюємо новою змінною; після розв’язання повертаємося до x.

Інфографіка: як не загубити корені

Алгоритм розв’язування

Парний степінь дає рівняння-наслідок. Остаточна перевірка виконується саме в початковому рівнянні.

Діаграма Ейлера: корені початкового рівняння та наслідку

У рівняння-наслідку можуть з’явитися додаткові, сторонні корені.

Наочний приклад: сторонній корінь

\(\displaystyle \sqrt{4+3x}=x\)

Після піднесення до квадрата отримуємо два кандидати: −1 та 4. Але ліва частина початкового рівняння невід’ємна, тому x = −1 не підходить. Відповідь: x = 4.

МАТЕМАТИЧНІ ПРИЙОМИ

6 лайфхаків для ірраціональних рівнянь

Коротке правило, формула та практична підказка — усе в одному місці.

01

Починай з ОДЗ

Спочатку встанови, за яких значень змінної всі корені парного степеня визначені.

\(\displaystyle \sqrt{x-5}\quad\Longrightarrow\quad x-5\geq0\quad\Longrightarrow\quad x\geq5\)

ОДЗ — перший фільтр для можливих коренів.

02

Ізолюй корінь

Перед піднесенням до квадрата залиш один радикал з одного боку рівняння.

\(\displaystyle \sqrt{f(x)}=g(x)\quad\Longrightarrow\quad f(x)=g^2(x)\)

Не забудь: потрібно перевірити умову g(x) ≥ 0.

03

Перевір знак

Арифметичний квадратний корінь ніколи не буває від’ємним.

\(\displaystyle \sqrt A=B\quad\Longrightarrow\quad B\geq0\)

Якщо права частина від’ємна, розв’язків немає.

04

Не довіряй квадрату

Піднесення до парного степеня може додати сторонні корені.

\(\displaystyle \sqrt{x+2}=x\quad\Longrightarrow\quad x+2=x^2\)

Отримані значення обов’язково підстав у початкове рівняння.

05

Бачиш повторення — заміни

Якщо в одному рівнянні є і квадратний корінь, і сама змінна, спробуй заміну.

\(\displaystyle t=\sqrt x,\quad t\geq0,\quad x=t^2\)

Після розв’язання рівняння відносно t повернися до x.

06

Шукай квадрат суми

Розпізнавай формули скороченого множення всередині складних підкореневих виразів.

\(\displaystyle x\pm2\sqrt{x-1}=\left(\sqrt{x-1}\pm1\right)^2\)

Ця тотожність діє за x ≥ 1; вона часто спрощує вкладені радикали.

ПЕРЕВІР СВОЇ ЗНАННЯ

6 запитань із теорії

Спробуй відповісти самостійно. Натисни на картку, щоб відкрити пояснення та формулу.

ПИТАННЯ 01Що називають ірраціональним рівнянням?+

Рівняння, у якому змінна міститься під знаком кореня.

\(\displaystyle \sqrt{x+3}=x-1\)
✓ Відповідь відкрито
ПИТАННЯ 02Чи завжди піднесення до непарного степеня зберігає множину коренів?+

Так. Піднесення обох частин рівняння до одного непарного натурального степеня є рівносильним перетворенням.

\(\displaystyle a=b\ \Longleftrightarrow\ a^{2k+1}=b^{2k+1}\)
✓ Відповідь відкрито
ПИТАННЯ 03Чому піднесення до квадрата може додати корені?+

Тому що протилежні числа мають однакові квадрати. Отримане рівняння може містити сторонні корені.

\(\displaystyle (-2)^2=2^2,\qquad -2\ne2\)
✓ Відповідь відкрито
ПИТАННЯ 04Яка умова для кореня з 3x − 6?+

Підкореневий вираз має бути невід’ємним.

\(\displaystyle \sqrt{3x-6}\quad\Longrightarrow\quad 3x-6\geq0\quad\Longrightarrow\quad x\geq2\)
✓ Відповідь відкрито
ПИТАННЯ 05Як знайти сторонній корінь?+

Підстав кожне отримане значення в початкове рівняння. Якщо рівність не виконується, корінь сторонній.

\(\displaystyle \sqrt{x+2}=x\quad\Longrightarrow\quad x=2\ \text{або}\ x=-1\)
✓ Відповідь відкрито
ПИТАННЯ 06Коли доречна заміна t = √x?+

Коли в рівнянні одночасно є квадратний корінь зі змінної та її степінь. Заміна дозволяє перейти до простішого рівняння.

\(\displaystyle t=\sqrt{x},\quad t\geq0,\quad x=t^2\)
✓ Відповідь відкрито

5 розібраних задач із підручника

Задача 1. Непарний корінь

\(\displaystyle \sqrt[7]{x^2-2}=\sqrt[7]{x}\)
  1. \(\displaystyle x^2-2=x\)
  2. \(\displaystyle x^2-x-2=0\)
  3. \(\displaystyle (x-2)(x+1)=0\)
  4. \(\displaystyle x=-1\ \text{або}\ x=2\)
Відповідь: \(\displaystyle x=-1,\ 2\)

Задача 2. Сторонній корінь

\(\displaystyle (\sqrt{3x+4})^2=(\sqrt{x-2})^2\)
  1. \(\displaystyle 3x+4=x-2\)
  2. \(\displaystyle x=-3\)
  3. \(\displaystyle x=-3\) не належить ОДЗ \(\displaystyle x\geq2\).
Відповідь: \(\displaystyle \varnothing\)

Задача 3. Перевірка коренів

\(\displaystyle \sqrt{4+3x}=x\)
  1. \(\displaystyle x\geq0\)
  2. \(\displaystyle 4+3x=x^2\)
  3. \(\displaystyle x^2-3x-4=0\)
  4. \(\displaystyle x=-1\ \text{або}\ x=4\)
  5. \(\displaystyle x=4\) — підходить; \(\displaystyle x=-1\) — сторонній корінь.
Відповідь: \(\displaystyle x=4\)

Задача 4. Два корені

\(\displaystyle \sqrt{2x-3}+\sqrt{4x+1}=4\)
  1. \(\displaystyle 2x-3\geq0\)
  2. \(\displaystyle 2\sqrt{(2x-3)(4x+1)}=18-6x\)
  3. \(\displaystyle 8x^2-10x-3\)=\(\displaystyle (9-3x)^2\)
  4. \(\displaystyle x^2-44x+84=0\)
  5. \(\displaystyle x=2\ \text{або}\ x=42\)
  6. \(\displaystyle \text{Перевірка: }x=2\ \text{підходить, }42\ \text{ні}\)
Відповідь: \(\displaystyle x=2\)

Задача 5. Заміна змінної

\(\displaystyle \sqrt{x^3+1}+2\sqrt[4]{x^3+1}-3=0\)
  1. \(\displaystyle t=\sqrt[4]{x^3+1},\quad t\geq0\)
  2. \(\displaystyle t^2+2t-3=0\)
  3. \(\displaystyle (t-1)(t+3)=0\)
  4. \(\displaystyle t=1\ \text{(значення }-3\ \text{відкидаємо)}\)
  5. \(\displaystyle \sqrt[4]{x^3+1}=1\Rightarrow x=0\)
Відповідь: \(\displaystyle x=0\)

\(\displaystyle \sqrt{x-4}+\sqrt{1-x}=5\)
Перевірити відповідь

Для коренів потрібно x≥4 та x≤1 одночасно — неможливо.

7.1 (4)Поясніть, чому рівняння не має коренів.
\(\displaystyle \sqrt[4]{x-6}+\sqrt{6-x}=1\)
Перевірити відповідь

Підкореневі вирази вимагають x≥6 та x≤6, отже x=6; тоді ліва частина 0≠1.
