Wyprawa po współrzędnych, nierównościach, zbiorach i liczbach

📖 Teoria — mapa królestwa liczb

Oś liczbowa to prosta z wybranym punktem 0, kierunkiem dodatnim i jednostką. Każdemu punktowi odpowiada liczba — jego współrzędna.
Współrzędna. Jeśli punkt A leży przy 6, zapisujemy A = 6. Odległość między sąsiednimi kreskami musi być stała.
Liczby na osi. Możemy zaznaczać liczby naturalne, całkowite, wymierne (np. 1/4, 3/2) i niewymierne (np. √2).
Puste kółko ○ oznacza: liczba graniczna nie należy do zbioru. Przykład: x < 5.
Pełne kółko ● oznacza: liczba graniczna należy do zbioru. Przykład: x ≤ 5.

Jak czytać nierówność?

x < 5 — wszystkie liczby na lewo od 5, bez 5.   x ≤ 5 — na lewo od 5 i także 5.
x > 3 — na prawo od 3, bez 3.   x ≥ −4 — na prawo od −4 i także −4.

💡 Największa liczba? W zbiorze x < 3 nie ma największej liczby: do każdej liczby mniejszej od 3 można znaleźć jeszcze większą, nadal mniejszą od 3.

🏠 Zadanie domowe

1. Narysuj oś i zaznacz zbiory: a) x ≥ −15, b) x < −15, c) x > −2,75, d) x > 1,25, e) x ≤ −8,5, f) x < −5, g) x > −12, h) x ≥ −2,8, i) x < −7.
2. Zaznacz liczbę i liczbę do niej przeciwną, a następnie odległość od 0: 5, −3, 7, 0.
3. Oblicz wartości bezwzględne: |−7|, |4|, |−5|, |0|.
4. Zaznacz na jednej osi liczby spełniające x < 8 i x ≥ 4. Wypisz wszystkie liczby całkowite spełniające oba warunki.
5. Dla par 248 i 252; 3 2/7 i 4 1/7; −0,03 i 0,03; −200 i 1400 oblicz średnią arytmetyczną i zaznacz ją na osi.
6. Wyjaśnij, dlaczego dla x < 3 nie istnieje największa liczba rzeczywista spełniająca warunek.
