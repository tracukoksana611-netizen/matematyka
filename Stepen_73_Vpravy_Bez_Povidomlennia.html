Степінь з раціональним показником

8 блоків теорії · 73 підпункти з повними умовами · місце для власного розв’язання · покрокова перевірка.

ТеоріяВправи6.16.26.36.46.56.66.76.86.96.106.116.126.136.146.156.166.176.186.19

Теорія: означення та властивості

1. Означення

\(\displaystyle a^{\frac{m}{n}}=\sqrt[n]{a^m}\)

Якщо a > 0, m — ціле, n — натуральне, n > 1. Знаменник n задає показник кореня, а чисельник m — степінь.

Приклад: \(\displaystyle 8^{\frac{2}{3}}=\sqrt[3]{8^2}=(\sqrt[3]8)^2=4\)

2. Нульовий і від’ємний показники

\(\displaystyle a^0=1,\qquad a^{-p}=\frac{1}{a^p}\)

Для нульового показника a ≠ 0; для раціонального p у наведених правилах a > 0.

Приклад: \(\displaystyle 25^{-\frac{1}{2}}=\frac{1}{\sqrt{25}}=\frac{1}{5}\)

3. Добуток степенів

\(\displaystyle a^p a^q=a^{p+q}\)

При множенні степенів з однаковими основами показники додають (a > 0).

Приклад: \(\displaystyle 2^{\frac{1}{3}}\cdot2^{\frac{2}{3}}=2\)

4. Частка степенів

\(\displaystyle \frac{a^p}{a^q}=a^{p-q}\)

При діленні степенів з однаковими основами показники віднімають (a > 0).

Приклад: \(\displaystyle 9^{\frac{5}{2}}:9^{\frac{3}{2}}=9\)

5. Степінь степеня

\(\displaystyle (a^p)^q=a^{pq}\)

При піднесенні степеня до степеня показники перемножують (a > 0).

Приклад: \(\displaystyle (16^{\frac{1}{2}})^{\frac{3}{2}}=16^{\frac{3}{4}}=8\)

6. Степінь добутку та частки

\(\displaystyle (ab)^p=a^pb^p,\quad\left(\frac{a}{b}\right)^p=\frac{a^p}{b^p}\)

Для додатних a і b та раціонального p.

Приклад: \(\displaystyle (4\cdot9)^{\frac{1}{2}}=2\cdot3=6\)

7. Степенева функція

\(\displaystyle y=x^r,\quad r\in\mathbb Q\)

Для додатного r область визначення [0; +∞), для від’ємного r — (0; +∞).

Приклад: \(\displaystyle y=x^{\frac{1}{2}}=\sqrt x\)

8. Особливі випадки

\(\displaystyle 0^{\frac{m}{n}}=0\ (m,n\in\mathbb N)\)

Степінь з основою 0 визначають для додатного раціонального показника. У підручнику степінь з від’ємною основою та дробовим показником не вводиться.

Приклад: \(\displaystyle 0^{\frac{2}{3}}=0,\quad 0^{-\frac{1}{2}}\ \text{не визначено}\)
